## 3. 融合机制

### 3.1 sharpe_weighted_sub 原理

```
每个交易日:
  for 每个模型 i ∈ [exp_43, exp_22, exp_5]:
    for 每个 ETF j:
      加权分数[j] += 模型预测分[i][j] × Sharpe权重[i]

  融合分数[j] = 加权分数[j] / 总权重[j]
  
  # score_power_3 策略
  偏移分[j] = 融合分数[j] - min(融合分数) + ε
  最终分[j] = 偏移分[j]³     # 3次方放大分差

  取最终分 Top-K → 调仓买入
```

### 3.2 模型权重（Sharpe 比率）

| 模型 | 权重(SR均值) | 说明 |
|---|---|---|
| tcn_43_3 | 2.904 | 最高 SR 均值，全 fold 稳定 |
| tcn_22_3 | 2.420 | 折间波动最小（CV=25.17） |
| tcn_5_3 | 2.376 | 回测实际收益最高（单模型 35.43%） |

### 3.3 为什么不使用 fold_ensemble

测试结果：对 4 个 fold 取平均预测后，3/4 的实验回测表现恶化。

| 模型 | fold_3 单折 | fold_ensemble(4折平均) | 变化 |
|---|---|---|---|
| tcn_5_3 | 35.43% | -2.92% | **恶化** |
| tcn_43_3 | 21.77% | — | 稀释信号 |
| tcn_22_3 | 10.33% | — | 稀释信号 |

> 原因：fold_3 验证期最接近当前回测窗口，信息价值最高。平均 4 个 fold 相当于引入了更早时期的噪音。

## 7. 配置说明

### 7.1 关键配置项

```yaml
# config.yaml (核心部分)
models:
  - dir: model/TSCV/bayes_tcn_74_3/exp_43/fold_3
    name: tcn_43_3
    weight: 2.904      # Sharpe 比率均值
  - dir: model/TSCV/bayes_tcn_74_3/exp_22/fold_3
    name: tcn_22_3
    weight: 2.420
  - dir: model/TSCV/bayes_tcn_74_3/exp_5/fold_3
    name: tcn_5_3
    weight: 2.376

sharpe_weighted_sub:
  enabled: true
  models: ["tcn_43_3", "tcn_22_3", "tcn_5_3"]
  weight_strategy: "score_power_3"
  position_pct: 0.90

master: "sharpe_weighted_sub"
```

### 7.2 运行流程

```bash
# 完整流程（数据更新 + 模型推理 + 回测 + 日报）
python code/src/daily_eval.py --predictions-only --no-update
python code/src/daily_eval.py --from-predictions --no-update

# 仅回测（已有 predictions.json 时）
python code/src/daily_eval.py --from-predictions --no-update
```

## 8. 风险提示

1. **回测局限**：当前验证期仅覆盖 2026-04~06（约 2 个月），未经历完整市场周期
2. **样本外验证**：fold_3（最新 fold）的验证期最接近当前，但仍需持续监控
3. **集中持仓风险**：score_power_3 仅 3 笔交易，集中在少数 ETF，需关注流动性
4. **模型衰减**：TCN 模型需定期重新训练（建议每月），防止市场结构变化导致失效
5. **备选方案**：若 score_power_3 表现下降，切换 score_risk_v1 分散风险
